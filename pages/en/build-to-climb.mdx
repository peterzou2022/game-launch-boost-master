# Build to Climb

Build to Climb is an online obby-style climbing game where height is everything. You gather blocks, stack them into taller structures, and keep pushing upward to reach better platforms, bigger drops, and stronger rewards. The loop is simple, but the constant chase for more height makes each run hard to put down.

## How to play

- **WASD** - Move
- **Right mouse hold** - Control the camera
- **Space** - Jump

## What makes Build to Climb fun

- Stacking blocks adds a building layer to the climbing challenge.
- Higher towers create riskier jumps and better reward moments.
- The obby structure gives the game a light Roblox-style feel.
- Quick restarts make it easy to keep improving.

## Smart ways to climb higher

- Build steadily instead of wasting blocks too early.
- Use the camera often so you can line up jumps more safely.
- Save some height for tricky sections rather than rushing every platform.
- Balance greed and safety when jumping down for rewards.
