# Drift Rush

Drift Rush 是一款强调控制感的在线漂移竞速游戏。它的乐趣不只是快，而是又快又稳。你需要在弯道前控制好节奏，在漂移中保持车身稳定，用更流畅的走线完成比赛，并积累更高的分数和奖励。

## 操作方式

- **W / 上方向键** - 加速
- **S / 下方向键** - 刹车或倒车
- **A / D** 或 **左右方向键** - 转向
- **Space / F** - 手刹漂移
- **Shift** - 氮气或漂移辅助（视模式而定）

## 为什么它玩起来很爽

- 长距离漂移的手感很顺，很有成就感。
- 赛道设计会不断逼你优化节奏和走线。
- 不同车辆的操控差异明显，体验不单调。
- 解锁和升级系统让每次比赛都有推进感。

## 漂移技巧

- 入弯别太猛，稳定比盲目提速更重要。
- 手刹别用过头，不然很容易甩过头。
- 长漂时适当松一点油门，更容易维持平衡。
- 先把短漂练稳，再追求长连漂。
- 多试几辆车，找到最适合自己手感的那一台。
