# Build to Climb

Build to Climb 是一款把“堆高”和“攀爬”结合在一起的在线 obby 游戏。你要收集方块，把它们垒成更高的塔，再借助高度跳向新的平台，争取拿到更多金币和更远的进度。规则不复杂，但越往上越容易让人停不下来。

## 操作方式

- **WASD** - 移动
- **按住鼠标右键** - 控制镜头
- **Space** - 跳跃

## 这个游戏为什么好玩

- 方块堆叠让普通攀爬多了一层建造感。
- 塔越高，跳跃和收益的风险回报越明显。
- 整体有轻松的 Roblox 风 obby 味道。
- 节奏快，失败后也能很快重新开始。

## 更容易爬高的小技巧

- 不要一开始就把方块全用掉，先稳一点往上堆。
- 多转镜头，确保跳跃路线看得清楚。
- 遇到难点时留一点高度储备，不要只顾着猛冲。
- 跳下去拿奖励前先判断值不值得冒险。
